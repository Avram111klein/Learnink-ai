# Learnink-ai

מנוע הבינה המלאכותית של Learnink לזיהוי כתב יד: מחולל כתב מלאכותי, מנוע קריאה, אימון ומדידה, ודף המאמן.

**אין כאן נתוני משתמשים.** כתב היד של הכותבים, בנק הסימנים, סטי הבדיקה והתרגילים המלאכותיים (שנבנים מהכתב) נשמרים רק בסביבת העבודה – לעולם לא במאגר. CROHME (רישיון לא-מסחרי) משמש למדידה בלבד ואינו כאן.

| תיקייה | מה |
|---|---|
| `generator/` | מחולל תרגילים בכתב של כותב, מסימנים אמיתיים שלו (רק מתרגילי אימון) |
| `reader/` | מנוע הקריאה: `hw_exp.js` (בשימוש בדף המאמן), `hw_exp2/3.js` (ניסויים שלא נכנסו) |
| `training/` | `base/` – אימון הבסיס (r3); `round1/`, `round2/` – סבבי אימון על כתב אמיתי |
| `models/` | v1 (r3), v2 (r4), v3 (r5) – 28 סימנים, int8, ~727KB; אומנו בלי CROHME |
| `trainer/` | דף המאמן (עותק); המודל מתפרסם לדף בנפרד |

בסקריפטים: `__WORKDIR__` = תיקיית העבודה, `__WRITER__` = מזהה הכותב – יש להגדיר לפני הרצה.
